# ОПИСиС · Интерактивные лекции

Курс «Основы построения информационных систем и сетей» для дистанционного обучения. Первая лекция — «От сообщения к сигналу»: введение в систему связи, OSI и TCP/IP, среду и канал, помехи, скорость и задержку, обзор OFDM и MIMO.

## Открыть лекцию

Откройте `index.html` в современном браузере. Внешних библиотек, сетевых шрифтов и установки зависимостей нет. Для стабильного сохранения прогресса используйте локальный сервер или GitHub Pages: поведение localStorage для `file://` зависит от браузера.

При установленном Node.js 18 или новее:

```powershell
npm run dev
```

Адрес: http://127.0.0.1:4173. Другой порт: `npm run dev -- --port 4180`.

Если в окружении доступен `node`, но отсутствует `npm`, запускайте напрямую: `node scripts/serve.mjs`.

## GitHub Pages

Сайт использует относительные пути и подходит для адреса репозитория вида `https://dusyapox.github.io/-/`.

1. Разместите файлы в ветке репозитория.
2. В GitHub откройте **Settings → Pages → Build and deployment**.
3. Выберите **Deploy from a branch**, нужную ветку и папку **/(root)**, затем **Save**.
4. Дождитесь публикации; точный адрес покажет GitHub в разделе Pages.

Это инструкция для владельца: наличие исходников само по себе не означает, что Pages уже включён. Публикация зависит от настроек и доступности GitHub Pages для репозитория.

## Что работает

- Три пошаговых сценария: точка–точка, Wi-Fi и сотовая сеть.
- Семь выбираемых уровней OSI с задачами, примерами и соответствием четырём уровням TCP/IP.
- Иллюстрация затухания, гауссовского шума и задержанного отражённого луча. Никакой выдачи рисунка за BER-расчёт.
- Калькулятор полезной скорости, времени выдачи пакета и распространения сигнала.
- Обзор OFDM/MIMO с переключением схем и объяснений.
- Десять вопросов с объяснением каждого ответа, повторная попытка, локальное сохранение ответов.
- Одна кнопка «Лекция пройдена» в конце, сохранение статуса лекции, сброс с подтверждением. Прежние отметки разделов автоматически учитываются при переходе: все восемь отметок означают завершённую лекцию; частичные отметки не завершают её.
- Расшифровки сокращений при введении терминов и подсказки при наведении; краткий словарь из восьми основных статей. Wi-Fi поясняется как торговое наименование.
- Адаптивная вёрстка, клавиатурная навигация, режим уменьшенного движения, печать/PDF через браузер.

Данные сохраняются только в браузере; серверного учёта результатов студентов и отправки преподавателю нет. Следующие лекции обозначены как готовящиеся, без неработающих переходов.

## Файлы

- `index.html` — текст и структура первой лекции.
- `styles.css` — оформление, адаптивность и печать.
- `lesson-model.js` — учебные данные, формулы, воспроизводимый шум и оценка теста; загружается и в браузере, и в Node.js.
- `app.js` — интерактивы и локальное состояние.
- `tests/lesson.test.cjs` — проверки формул, свойств сигнала, теста и целостности страницы.
- `scripts/serve.mjs` — локальный сервер без зависимостей.

## Проверки

```powershell
npm run check
```

Без npm: `node --check app.js`, `node --check lesson-model.js`, `node --test tests/lesson.test.cjs`.

Дополнительно проверяйте страницу в браузере на настольном и мобильном размерах: прохождение маршрутов, выбор уровней, регуляторы, незаполненный тест, повторную попытку и восстановление прогресса после перезагрузки.

## Методические границы

Предварительная программа: восемь лекций; продолжительность первой — ориентировочно 60–75 минут с исследованиями и самопроверкой. Эти значения не являются утверждённой нагрузкой.

Демонстрации упрощены и подписаны. Канал не привязан к конкретному стандарту. Калькулятор не моделирует очереди, повторы и обработку: `L = 12 000 бит`, `v = 200 000 км/с`, `Rпол = R(1 − α)`, `tперед = L/R`, `tраспр = d/v`. OFDM и MIMO введены концептуально; подробный разбор предназначен для следующих лекций. Карта TCP/IP принята четырёхуровневой, с пояснением пятиуровневого учебного варианта.

В конце лекции приведены ссылки на ITU-T X.200, RFC 1122 и документацию MathWorks по OFDM/MIMO. Реализация не требует MATLAB или его лицензии.
